# PD2-PerkDeckTemplates
Mod page: https://modworkshop.net/mod/60055
A template perk deck mod for PAYDAY 2. This version requires [SuperBLT](https://superblt.znix.xyz/) and [BeardLib](https://modworkshop.net/mod/14924). It contains placeholder code and art, and includes a custom throwable ability and sync fix code. 
This is essentially a structural template for a custom perk deck mod; if you want a working example, search [the perk decks category in ModWorkshop](https://modworkshop.net/g/payday-2?category=646).
